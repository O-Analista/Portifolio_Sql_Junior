🛒 Projeto 01 — E-commerce

Análise de Vendas E-commerce

Objetivo: Analisar os dados de vendas de um e-commerce utilizando SQL Server, identificando faturamento, desempenho de produtos, categorias, vendedores e comportamento dos clientes. Principais análises: Faturamento total Faturamento por categoria Produtos mais vendidos Ranking de vendedores Ticket médio Vendas por período Melhores clientes Categorias acima da média Ranking com RANK() Classificação de produtos com CASE Tecnologias: SQL Server • T-SQL • JOIN • GROUP BY • HAVING • CTE • Window Functions Resultado: As consultas transformam os dados brutos do e-commerce em informações úteis para apoiar decisões comerciais, como identificar produtos de maior desempenho, categorias mais rentáveis e vendedores com melhores resultados.

ANÁLISE 01 / 10

Faturamento Total

Qual o faturamento total? 


SELECT
    SUM(ip.Quantidade * ip.Preco_Unitario) AS Faturamento_Total
FROM ItensPedido ip

INNER JOIN Pedidos p
    ON ip.ID_Pedido = p.ID_Pedido

WHERE p.Status_Pedido = 'Concluído';
RESULTADO
Insight

A consulta permite identificar o faturamento total considerando apenas os pedidos concluídos.

ANÁLISE 02 / 10

Faturamento por Categoria

Quais categorias apresentam maior faturamento? 


--ANÁLISE 02 FATURAMENTO POR CATEGORIA
SELECT
    c.Nome_Categoria AS Categoria,

    SUM(
        ip.Quantidade * ip.Preco_Unitario
    ) AS Faturamento

FROM ItensPedido ip

INNER JOIN Pedidos p
    ON ip.ID_Pedido = p.ID_Pedido

INNER JOIN Produtos pr
    ON ip.ID_Produto = pr.ID_Produto

INNER JOIN Categorias c
    ON pr.ID_Categoria = c.ID_Categoria

WHERE p.Status_Pedido = 'Concluído'

GROUP BY c.Nome_Categoria

ORDER BY Faturamento DESC;
RESULTADO
Insight

A análise permite identificar quais categorias são responsáveis pela maior parcela do faturamento.

TICKET-MÉDIO

Quais produtos possuem maior volume de vendas? 


--ANÁLISE 05 TICKET-MÉDIO 

SELECT
    AVG(Total_Pedido) AS Ticket_Medio

FROM (

    SELECT
        p.ID_Pedido,

        SUM(
            ip.Quantidade * ip.Preco_Unitario
        ) AS Total_Pedido

    FROM Pedidos p

    INNER JOIN ItensPedido ip
        ON p.ID_Pedido = ip.ID_Pedido

    WHERE p.Status_Pedido = 'Concluído'

    GROUP BY p.ID_Pedido

) AS PedidosTotais;
RESULTADO
Insight

A consulta identifica o ticket-medio dos produtos.

ANÁLISE 06 / 10

VENDAS POR ANO,MÊS,DIA

Quais produtos mais venderam por ano dia e mês? 


--ANÁLISE 06 — VENDAS POR ANO,MÊS,DIA
SELECT
    YEAR(p.Data_Pedido) AS Ano,
    MONTH(p.Data_Pedido) AS Mes,
    DAY(p.Data_Pedido) AS Dia,

    SUM(ip.Quantidade * ip.Preco_Unitario) AS Faturamento

FROM Pedidos p

INNER JOIN ItensPedido ip
    ON p.ID_Pedido = ip.ID_Pedido

WHERE p.Status_Pedido = 'Concluído'

GROUP BY
    YEAR(p.Data_Pedido),
    MONTH(p.Data_Pedido),
    DAY(p.Data_Pedido)

ORDER BY
    Ano,
    Mes,
    Dia;
RESULTADO
Insight

A consulta identifica vendas por ano dia e mes.

ANÁLISE 07 / 10

MELHORES CLIENTES

Quais os melhores clientes? 


SELECT
    c.Nome_Cliente AS Cliente,

    COUNT(DISTINCT p.ID_Pedido) AS Quantidade_Pedidos,

    SUM(
        ip.Quantidade * ip.Preco_Unitario
    ) AS Valor_Total

FROM Clientes c

INNER JOIN Pedidos p
    ON c.ID_Cliente = p.ID_Cliente

INNER JOIN ItensPedido ip
    ON p.ID_Pedido = ip.ID_Pedido

WHERE p.Status_Pedido = 'Concluído'

GROUP BY c.Nome_Cliente

ORDER BY Valor_Total DESC;
RESULTADO
Insight

A consulta identifica os melhores clientes.

ANÁLISE 08 / 10

CATEGORIA ACIMA DA MÉDIA

Quais produtos tem categoria acima da madia? 


WITH FaturamentoCategoria AS (

    SELECT
        c.Nome_Categoria AS Categoria,

        SUM(
            ip.Quantidade * ip.Preco_Unitario
        ) AS Faturamento

    FROM Categorias c

    INNER JOIN Produtos pr
        ON c.ID_Categoria = pr.ID_Categoria

    INNER JOIN ItensPedido ip
        ON pr.ID_Produto = ip.ID_Produto

    INNER JOIN Pedidos p
        ON ip.ID_Pedido = p.ID_Pedido

    WHERE p.Status_Pedido = 'Concluído'

    GROUP BY c.Nome_Categoria
)
SELECT
    Categoria,
    Faturamento

FROM FaturamentoCategoria

WHERE Faturamento >
(
    SELECT AVG(Faturamento)
    FROM FaturamentoCategoria
)
ORDER BY Faturamento DESC;
RESULTADO
Insight

A consulta identifica Categoria de produtos acima da media.

ANÁLISE 09 / 10

RANKING DE VENDEDOR E FATURAMENTO COM RANK()

Quais vendedores do raking tem maiores faturamento? 



WITH VendasVendedor AS (

    SELECT
        v.Nome_Vendedor AS Vendedor,

        SUM(
            ip.Quantidade * ip.Preco_Unitario
        ) AS Faturamento

    FROM Vendedores v

    INNER JOIN Pedidos p
        ON v.ID_Vendedor = p.ID_Vendedor

    INNER JOIN ItensPedido ip
        ON p.ID_Pedido = ip.ID_Pedido

    WHERE p.Status_Pedido = 'Concluído'

    GROUP BY v.Nome_Vendedor

)

SELECT
    Vendedor,
    Faturamento,

    RANK() OVER (
        ORDER BY Faturamento DESC
    ) AS Ranking

FROM VendasVendedor

ORDER BY Ranking;
RESULTADO
Insight

A consulta identifica o ranking de vendedores e faturamento.

ANÁLISE 10 / 10

Produtos Mais Vendidos

Quais produtos estao com baixa ou alta? 


SELECT
    pr.Nome_Produto AS Produto,

    SUM(ip.Quantidade) AS Quantidade_Vendida,

    CASE

        WHEN SUM(ip.Quantidade) >= 5
            THEN 'Alto Volume'

        WHEN SUM(ip.Quantidade) >= 3
            THEN 'Volume Médio'

        ELSE 'Baixo Volume'

    END AS Classificacao

FROM Produtos pr

INNER JOIN ItensPedido ip
    ON pr.ID_Produto = ip.ID_Produto

INNER JOIN Pedidos p
    ON ip.ID_Pedido = p.ID_Pedido

WHERE p.Status_Pedido = 'Concluído'

GROUP BY pr.Nome_Produto

ORDER BY Quantidade_Vendida DESC;
RESULTADO
Insight

A consulta identifica os produtos com baixa e alta.
